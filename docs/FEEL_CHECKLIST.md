# Feel checklist (side-by-side review against the reference genre)

Tick each item only after verifying in the running game.

## Input responsiveness
- [ ] Jab (1) starts on the frame after the key press (10f startup counted from press).
- [ ] No visible input lag between tap and animation start at 60 fps.
- [ ] Dash (f,f) and backdash (b,b) register with up to a 10-frame gap.
- [ ] Crouch-dash and wavedash inputs parse reliably.

## Hit-stop
- [ ] Light hits freeze both fighters ~4f; heavies ~10f; launchers ~12f.
- [ ] Hit-stop freezes animation but the camera shake plays through it.

## Block / sidestep
- [ ] Holding back blocks highs and mids; lows connect.
- [ ] Crouch-block blocks lows; highs whiff over a crouching fighter.
- [ ] A sidestep evades a linear attack but not a homing attack.
- [ ] Tracking is asymmetric (strong/weak side).

## Juggles
- [ ] Launcher lifts the opponent with weight; successive hits lift less.
- [ ] Combo damage scales; bound hits allow a ground re-pickup once.
- [ ] Wall splat holds the opponent on the wall for a follow-up.

## Camera
- [ ] Side-on framing with both fighters, zooms with distance.
- [ ] Punch-in on heavy hits, slow-motion KO camera.
